## Implementation Routing

### Phase 1: Build Infrastructure (Backend Developer)

**Tasks 1.1-1.5: Build-time key embedding system**

**Agent:** Backend Developer  
**Parallelization:** Sequential (foundation for all phases)  
**Estimated Duration:** 4-6 hours

**Task Details:**

1. **Task 1.1:** Create `scripts/build-keys.ps1`
   - PowerShell script to process `build-keys.json`
   - Read JSON array of key configurations
   - Validate each key file exists and is readable
   - Check file permissions (warn if > 0600)
   - Derive machine-bound encryption key: `SHA256(MachineGUID + "|" + exeDir)`
   - Encrypt each key content with AES-256-GCM
   - Base64 encode ciphertext
   - Generate `internal/keys/embedded.go` with two maps:
     - `EmbeddedKeys map[string]string` (id → base64 encrypted key)
     - `EmbeddedKeyMetadata map[string]string` (id → description)
   - Exit with error code if validation fails

2. **Task 1.2:** Create `build-keys.json.example`
   - Example configuration file (git-tracked)
   - JSON array format with 2-3 sample entries
   - Include comments explaining each field
   - DO NOT include real key paths
   - Show examples: absolute path, relative path, env var

3. **Task 1.3:** Update `.gitignore`
   - Add `/internal/keys/embedded.go` (generated file)
   - Add `/build-keys.json` (contains real key paths)
   - Ensure these are excluded from version control

4. **Task 1.4:** Modify `build.bat`
   - Before `wails build`, add:
     ```batch
     if exist build-keys.json (
         echo Embedding SSH keys...
         powershell -ExecutionPolicy Bypass -File scripts\build-keys.ps1
         if %errorlevel% neq 0 (
             echo Key embedding failed!
             exit /b %errorlevel%
         )
     ) else (
         echo No build-keys.json found, using template (no embedded keys)
         copy /Y internal\keys\embedded.go.template internal\keys\embedded.go >nul
     )
     ```
   - Handle both cases: keys present or absent

5. **Task 1.5:** Create `internal/keys/embedded.go.template`
   - Template file used when `build-keys.json` missing
   - Contains:
     ```go
     // Code generated by build process. DO NOT EDIT.
     package keys

     // EmbeddedKeyMetadata stores key descriptions
     var EmbeddedKeyMetadata = map[string]string{}

     // EmbeddedKeys stores encrypted private key content
     var EmbeddedKeys = map[string]string{}
     ```
   - Empty maps (no embedded keys)

**Acceptance Criteria:**
- [ ] `build-keys.ps1` successfully parses JSON and generates valid Go code
- [ ] Build succeeds with `build-keys.json` present (generates embedded.go with keys)
- [ ] Build succeeds without `build-keys.json` (uses template, empty maps)
- [ ] `.gitignore` prevents committing generated file and real config
- [ ] Build fails with clear error if key file missing
